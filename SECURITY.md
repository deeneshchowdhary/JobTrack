# Security policy

## Supported versions

JobTrack is in early development. Security fixes are applied to the latest code
on `main`; there are not yet multiple supported release lines.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
**Report a vulnerability** option in the repository Security tab to submit a
private security advisory. Include the affected component, reproduction steps,
potential impact, and any suggested mitigation.

The maintainer will acknowledge the report when it is reviewed and coordinate
disclosure after a fix is available. If private vulnerability reporting is not
enabled, open a public issue containing no sensitive details and ask for a
private contact channel.
